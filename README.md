**ONE DAY, ONE SPINE** — A dense cream broadsheet capturing every major story of Wednesday 25 November 2026 in a single 1024×1024 image.

## The Twist
A VERTICAL UTC SPINE down the left edge: the day's 24 hours as a vertical rail with time-markers, the 3 leads + cards hanging off it in UTC order, so the whole page reads as a day unfolding top-to-bottom. Same winning newspaper formula, own layout.

## Formula Execution
- **Masthead** + huge serif date headline + story/region counts
- **Vertical UTC spine** — 24-hour rail with time-markers, leads + cards in UTC order
- **3 lead panels** with drawn scenes + status tags + source lines
- **Card grid** — 8–12 smaller cards with icons, location/topic labels, bold headlines, short decks, status tags + sources
- **WHERE IT HAPPENED** — dotted world map with pins matching story locations
- **ALSO ON** — numbered list for the remaining stories
- **THE DAY IN NUMBERS** — 3–5 stats panel
- **DATE CHECK** box explicitly excluding 24 Nov news
- **Footer** with named source credits
- **Zero clipping** — every headline complete
